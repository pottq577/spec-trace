# 최종설계의 결정 근거를 어떻게 추적하는가

## 최종설계서와 결정 근거 추적

최종설계서의 중요한 정책은 기획 원문부터 채택 결과까지 역추적할 수 있어야 한다.

추적 흐름은 다음과 같다:

1. 최종설계 정책
2. 개발 결정 또는 기획자 결정
3. 검토사항
4. 근거와 기획 원문 / 관련 설계서 / 기존 코드
5. 선택지와 트레이드오프
6. 채택 결과

이 추적 관계를 통해 몇 달 뒤에도 현재 코드가 기획 원문과 다른 이유를 확인할 수 있다.
