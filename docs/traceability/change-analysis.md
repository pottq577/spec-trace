# 기획 변경과 개발 영향을 어떻게 구분해 분석하는가

## 변경 추적의 비교 기준

개발 중 기획 변경은 두 단계로 비교한다.
두 비교는 서로 다른 질문에 답한다.

### 원문 변경 비교

원문 변경 비교(Source Diff)는 "기획자가 실제로 무엇을 바꿨는가"를 확인한다.

- 비교 대상: `이전 기획 원문 ↔ 신규 기획 원문`

결과는 의미 변경, 추가, 삭제, 조건 변경, 표현 변경으로 분류한다.

### 영향 분석

영향 분석(Impact Analysis)은 "이번 변경이 현재 설계와 개발에 무엇을 바꾸는가"를 확인한다.

- 비교 대상: `신규 기획 원문` 대비
  - `현재 최종설계서`
  - `기존 결정`
  - `현재 코드베이스`
  - `선행 작업`
  - `관련 설계서`

이 구분을 통해 기획자가 새로 수정한 내용과 기존 개발 결정 때문에 이미 달라진 내용을 섞지 않는다.
